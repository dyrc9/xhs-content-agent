# Contributing

This project is a creator tool, not a spam or engagement automation tool.

Accepted contribution areas:

- better draft generation
- content quality checks
- calendar planning
- publish package formats
- manual browser assistance with human confirmation
- evaluation fixtures for note quality

Out of scope:

- fake likes, follows, comments, or views
- captcha bypass
- login or rate-limit evasion
- mass posting without human review
- scraping private or restricted content

Verify changes with:

```bash
python3 -m unittest discover -s tests
python3 -m compileall src tests
```
